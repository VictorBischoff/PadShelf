# App artwork

`AppIcon.png` is the master sketch icon, generated with the built-in image-generation tool. The user's supplied front-view SP-404SX photograph is the authoritative layout reference. It is not redistributed in this repository. `PadShelf.icns` is generated with Apple's `sips` and `iconutil` for sizes from 16 through 1024 pixels. Previous icons remain in Git history.

The icon follows the four top knobs, red circular display, three control tiers, twelve numbered pads in four columns and three rows, and the separate utility-pad column. Orange performance pads are 1, 3, 6, 8, 10 and 11.
