# App artwork

`AppIcon.png` is the master artwork for a simple hand-drawn SP-404SX-inspired icon, created with the built-in image-generation tool. `PadShelf.icns` packages the PNG using Apple's `sips` and `iconutil`; the build script generates icon sizes from 16 through 1024 pixels. No creative edits are applied during packaging.

The previous icon is retained in Git history. The redesign used that icon as the edit target and a [front-view SP-404SX photograph](https://zedem.ca/cdn/shop/files/sp-404sx_top_gal_1024x1024.jpg?v=1697807572) as a device-layout reference. The photograph is not bundled with the project.
